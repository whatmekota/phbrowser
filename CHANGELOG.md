# Changelog

## 0.1.0

First version, for playhound 2.0's desktop app.

- A **Browser** page on the stage: address bar with search, back, forward, reload and stop, home, the page title and a loading bar.
- Up to 12 bookmarks under the bar; the last page comes back next time.
- Settings: home page, search address, page zoom.
- A palette command, **Open the browser**.
